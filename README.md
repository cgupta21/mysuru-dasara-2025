# 🏰 Mysuru Dasara 2025

A responsive and interactive website showcasing **Mysuru Dasara 2025 – Karnataka's Royal Heritage Festival**.

The website provides information about the history, cultural significance, daily schedule, major attractions, special events, and traditions associated with Mysuru Dasara.

## 🌐 Live Demo

**Live Website:**
https://mysurudasara2k25.netlify.app/

## 📖 About the Project

Mysuru Dasara is one of Karnataka's most famous cultural festivals and is celebrated as the state festival, **Nadahabba**.

This project presents information about Mysuru Dasara 2025 through a modern and interactive website.

The website highlights major events such as:

* 🐘 Jamboo Savari
* 🏰 Mysore Palace Illumination
* 🚁 Drone Show
* 🙏 Ayudha Puja
* 🎭 Cultural Programs
* 🎨 Traditional Events
* 📅 Daily Dasara Celebrations
* 📸 Festival Gallery
* ℹ️ Visitor Information

## 🌟 Major Attractions

### 🐘 Jamboo Savari

The grand elephant procession is one of the main highlights of Mysuru Dasara and represents the royal traditions and cultural heritage of Karnataka.

### 🏰 Mysore Palace Illumination

The Mysore Palace is illuminated during the Dasara celebrations, creating one of the most iconic views of the festival.

### 🚁 Drone Show

The website highlights the spectacular drone show planned as part of the Mysuru Dasara 2025 celebrations.

### 🙏 Ayudha Puja

A special section explains Ayudha Puja, its traditions, ceremonies and cultural significance.

## 🎯 Purpose of the Project

The purpose of this project is to create an informative and visually attractive website that helps users explore the cultural heritage, traditions and major events of **Mysuru Dasara 2025**.

It also demonstrates practical implementation of front-end web development concepts using **HTML, CSS and JavaScript**.
